# Secondary Emission Monitor Fundamentals

An interactive educational explainer for Secondary Emission Monitor (SEM) physics and detector design, built with React and Vite.

🔗 **Live Demo:** [https://froncaro.github.io/bi-pm-sem](https://froncaro.github.io/bi-pm-sem)

## Overview

This interactive web application explains the fundamental physics and engineering principles behind Secondary Emission Monitors (SEMs) used for beam profile measurement at CERN and other particle accelerators.

### Topics Covered

- **Secondary Emission Physics** — How energetic particles generate secondary electrons
- **Detector Geometry** — SEM grid design with signal wires and bias configuration
- **Signal Formation** — How secondary electrons are collected and measured
- **Practical Applications** — Real-world SEM implementations for beam diagnostics

## Development

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

This will build the project and push to the `gh-pages` branch.

## Technology Stack

- **React 18** — UI components
- **Vite** — Build tool and dev server
- **gh-pages** — GitHub Pages deployment
